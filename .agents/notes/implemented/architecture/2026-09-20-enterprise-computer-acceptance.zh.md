# Agent Note: 企业云电脑资料授权与验收

Status: implemented

[English](2026-09-20-enterprise-computer-acceptance.md) | 中文

## 问题

外部自主电脑可能在本地连接停止后继续执行。租约重试、执行方完成消息及本地取消，都不能证明外部动作已经停止或可用成果确实存在。

## 决策

[企业云电脑模块](../../../../trade/enterprise/computers.md) 在企业任务旁持久化执行分配。每个绑定都有可撤销、只保存摘要的 HTTP 凭据；服务端确定执行方身份，并落实任务级文件授权。任务输入及岗位说明在创建时固定。已有企业文件库存储上传字节；任务审批及审计记录复用各自的存储所有者。人工验收与执行方提交分离。

每个工位只能有一个已领取且未终结的任务。重复领取返回同一任务，不创建新的执行尝试；长时间无回报不会自动重试。已领取任务的取消只记录请求，需要认证执行方确认停止。断开连接记录不确定状态并撤销访问，不宣称远程执行已经终止。认证连接器在线不证明供应商账号所有权、机器健康或供应商推送与停止能力。

[本地企业所有权决策](2026-09-14-local-enterprise-workspace.zh.md) 继续负责持久化及共享登录范围。[Grokbot 任务桥接](../feature/2026-09-15-grokbot-task-bridge.zh.md) 继续负责独立的租约队列；本模块不挂载或修改它，因为其重试与取消语义不能授权自主企业操作的副作用。

电脑概览展示读取到的任务状态示意，不代表供应商遥测。单独标注的动效预览只改变本地展示状态，不写入任务分配。连接动画表示本地读取或演示，不表示供应商连接已认证；完成状态要求成果已验收。显式暂停和系统减少动态效果控制支持无动画查看所有状态。这种区分避免视觉活动声称未经观察的执行状态或引导重复操作。

单独打开的云电脑控制台通过主动回连的 Python 连接器，在已有 X11 桌面上可选启用 MSS 截图和 xdotool 输入。Host 计时的心跳确定连接器在线状态。查看需求限制画面保留；截图和指令保持为临时状态，不进入持久化任务或 Session 数据。输入必须引用当前连接器实例及近期画面，只派发一次，确认前阻止后续输入。回执丢失进入不确定状态，不自动重试。重启、凭据轮换和断开会使中继状态失效。供应商创建电脑和自然语言执行属于独立集成；桌面输入是显式人工控制，不是模型可见工具。

按账号配置的 Routine Webhook 通知 Grok Bot 检查其已有任务。地址和发送密钥引用从 Host 环境解析；浏览器快照不含供应商密钥。发送请求前先持久化派发记录。HTTP 200 只确认唤醒；中断的派发在重启后仍为未知，不会重试。Python 连接器提供检查版本的任务命令并核对上传哈希，自然语言执行由外部 Bot 负责。Routine 说明不进入 Harness Session，因此预期输出保存在所属模块。真实账号执行仍需要供应商侧 Routine 和由运维核实的成果往返。

## 考虑过的替代方案

**复用过期任务租约。** 心跳缺失无法区分执行方停止和动作已执行但回执丢失。自动重新执行可能重复外部写入。

**信任执行方成功或任意成果 URL。** 执行方不能赋予成功状态。必需成果通过现有内容验证的文件上传路径提交，由人工检查实际结果。任意 Host 路径或远程 URL 抓取会增加与任务无关的访问权限。

**把供应商 Bot 名称当作租户隔离。** 岗位无法隔离同一账号共享的文件和登录态。本部署明确服务一家企业，不同信任范围需要独立供应商账号。绑定标识是运维人员声明，不是供应商验证。

## 影响

SQLite schema 版本 13 保存任务分配及凭据摘要。事务及已观察版本拒绝过期状态变更。审批后的继续执行要求企业任务已获批准且未修改。未领取任务可以本地取消，已领取任务在执行方确认停止前保留不确定性。已撤销访问的进行中上传可能作为企业素材保留，供检查，但不会被验收为任务成果。

定向源码测试覆盖身份、重复创建、审批版本检查、必需文件和取消。构建后的 `dsh` Web 配置测试覆盖浏览器、认证 HTTP 执行方、真实文件字节，以及桌面和手机上的人工验收。真实 Grokbot 账号连通性、自动调度、MCP 传输、模型自主委派和模型 Session 录制回放尚未包含在本模块已验证的行为中。
