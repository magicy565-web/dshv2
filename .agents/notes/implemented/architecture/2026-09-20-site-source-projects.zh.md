# Agent Note: Site source projects independent of commerce

Status: implemented

## Problem

Workspace 网站需要跨会话保留可编辑源码和二进制资源。强制 Shopify 连接且只存储页面标题，会阻止独立网站的创建和维护。

## Decision

Site 服务保存不可变源码项目版本，销售连接为可选项。静态项目构建为关联明确版本的确定性文件产物。Next.js 源码可以存储但不执行；运行前必须具备隔离的框架构建提供方。源码解析拒绝不安全的跨平台路径、凭据文件名和无效二进制编码。

企业部署负责站点存储和可信租户身份。站点工具支持创建项目、读取指定版本、校验版本后修改文件、预览静态项目和恢复草稿。工具输入和结果进入现有工具调用 Session 日志。私有预览仅编译虚拟项目文件，并在不透明来源沙箱中运行浏览器代码；编译器不解析 Host 文件或 Host 依赖。

独立托管分别记录源码版本和提供方构建。企业使用方采用可替换的提供方接口及独立 SQLite 记录。Vercel 提供方使用受保护的部署地址构建正式环境版本，并关闭域名自动分配。人工发布确认绑定现有构建和源码摘要，因此后续草稿修改不会改变被发布的内容。提交成功不表示正式路由已切换：只有查询提供方确认后才更新线上记录。未确认的提交保留检查点，并按请求标识和摘要查询恢复，不重复提交。

[Shopify 能力决策](2026-09-15-shopify-site-capability-seams.md) 继续负责销售提供方分离和发布任务。[销售功能完成提案](../../proposed/architecture/2026-09-15-shopify-site-completion.md) 面向可选销售层，不将销售连接作为独立网站的前提。

## Alternatives considered

**继续强制 Shopify。** 放弃，因为企业网站、游戏和内部应用可以没有店铺，其源码生命周期属于 Workspace。

**在企业 Host 执行生成的构建脚本。** 放弃，因为 Host 持有企业文档和服务凭据。静态预览编译只解析虚拟文件；服务端框架构建需要单独执行环境。

**只存储生成的 HTML。** 放弃，因为可编辑模块和二进制资源必须支持历史比较和恢复。源码项目和构建产物使用不同表示。

**发布时重新构建最新草稿。** 放弃，因为结果可能与已检查的预览不同。待发布的正式环境构建在提升或回滚时保留部署标识。

**重试每个失败的云端请求。** 放弃，因为响应丢失可能发生在外部成功接受请求之后。持久检查点避免网络故障或进程重启后重复提交。

## Consequences

SQLite 恢复、版本比较和回滚均保留项目文件。仅 Shopify 发布操作会因缺少销售连接失败。单元测试和企业 Host 测试覆盖源码保留、过期编辑拒绝、预览隔离及工具清理。提供方测试覆盖构建、明确构建发布、并发和恢复；浏览器测试使用保存的源码及模拟云端响应验证发布审核。云端凭据保留在部署配置中，不进入生成源码。Vercel 集成仍需实际账号验证；访问权限、域名和持久应用数据仍未完成。本地测试不能证明完整 Sites 产品或真实云发布成功。
