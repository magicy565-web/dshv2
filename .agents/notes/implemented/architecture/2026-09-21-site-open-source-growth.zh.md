# Agent Note：开源网站发现、统计与公开咨询

Status: implemented

[English](2026-09-21-site-open-source-growth.md) | 中文

## Problem

企业网站需要可发现的产品回答、流量证据和询盘路径，同时不依赖付费统计或第二套 Agent 平台。复用已认证的工作空间 Agent 会向匿名访客暴露工具与私有上下文。

## Decision

企业消费者把获准公开的公司事实编排为普通版本化源码。采购指南、可见 FAQ 回答和结构化数据保留相同事实与限制。维护中的 parse5 和 sitemap 库负责发布元数据及发现输出。公开网址和集成配置参与编译摘要，检查另一个来源不会覆盖同一源码版本的线上构建。本地数据库使用单调迁移，保留已有发布内容并按摘要索引构建。

自托管 Umami 负责流量采集和报表。发布页面使用其官方追踪器，私有工作空间读取指标并链接到其报表。适配器保留有界 UTM 字段，移除其他查询参数和引荐路径，不把询盘内容或咨询文本作为统计属性发送。浏览器报告的归因未经验证。持久化询盘回执、浏览量、AI 引荐和爬虫观察是不同证据；爬虫 User-Agent 声明及人工提供的模型引用属于观察，不代表经过验证的结果。

公开咨询复用 Harness 循环，明确选择模型路由，创建新的 Session，使用完整的公开资料提示词且不提供工具。匿名 API 接收有界问题和历史，不接收工作空间 Session 标识。发布事实属于不可信参考资料，不是高权限指令。取消会释放 Agent，配额跨重启保留，发布变化会使等待中的回答失效。咨询日志沿用现有 Session 机制，由运营者负责保留。访客明确操作后才将回答复制到询盘表单，持久化接收回执与模型文本保持独立。

不透明页面沙箱仅允许向自身询盘接口、可选咨询接口及配置的 Umami 来源发起请求。统计凭据不进入源码。本地模型与自托管 Umami 无需付费服务订阅；部署和运维仍由管理员负责。

[源码项目决策](2026-09-20-site-source-projects.zh.md)继续负责版本、源码隔离与发布。[Shopify 能力决策](2026-09-15-shopify-site-capability-seams.zh.md)和[商务完成提案](../../proposed/architecture/2026-09-15-shopify-site-completion.zh.md)保留独立商务范围。这些可选企业集成没有替代其决策理由。

私有运营中心读取 Umami 指标，并接入 SearXNG 搜索、ntfy 通知和 EspoCRM 标准 Lead API。外部写入在发送前持久化占用，不确定回执保持未知，等待管理员核对或确认重试。搜索结果、人工引用、官网模型实测和未验证 User-Agent 计数是不同证据，不能合并为 AI 排名。独立企业部署复用现有授权，不添加共享多租户账号。

私有工作空间区分网站编辑、发布、询盘和统计，并在这些标签间保留表单。未保存内容和设置会阻止替换所选网站或版本。Sites 面板存在未保存修改或内容、设置操作时，会注册同步的布局导航检查；被拒绝的全局面板切换保留表单，并提示如何继续。React 卸载和插件释放都会注销检查。保存失败保留输入，编辑会清除公开内容确认。统计刷新保留用户检查过的设置版本，避免无关报表授权覆盖较新的设置。专题建议包含选型事实与限制，不能仅凭应用标签生成，也不生成内容相同的行业页和方案页。

## Alternatives considered

**另行实现统计数据库和报表。**拒绝：Umami 已负责采集、归因和报表。少量集成代码可以避免维护另一套指标实现。

**嵌入独立 Agent 平台或复用编辑器会话。**拒绝：现有循环已提供模型路由、取消和 Session 日志，而匿名访问需要独立的公开上下文及无工具权限。

**为补齐营销页面生成无依据的主张。**拒绝：缺少证据不能支撑证书、案例、价格或竞品比较。缺失事实保持明确缺省。

## Consequences

已保存版本保留发现元数据和集成选择。下线会停止发现文件、咨询及新询盘访问。流量报表需要运营者提供 Umami 实例；浏览器测试模拟其外部接口。咨询浏览器测试仅脚本化外部模型，执行真实 profile 与循环。本地模型真实质量、公网 DNS、TLS 和真实 Umami 部署仍需单独验证。模板目录 Session 回放负责模型可见参数 schema。
