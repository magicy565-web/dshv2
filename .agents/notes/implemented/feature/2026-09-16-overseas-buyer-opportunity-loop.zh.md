# Agent Note：海外买家研究形成持久机会

状态：已实现

[English](2026-09-16-overseas-buyer-opportunity-loop.md) | 中文

## 决策

海外买家研究是企业部署随附的 Skill。Skill 规定目标澄清、来源选择、采购信号核查、匹配评分、不确定信息处理、去重和跟进结果展示，不负责持久化、授权、输入校验或外部沟通。

同一个插件还随附企业与产品建档、供应商评估、产品利润、小品牌定位和询盘回复方法。这些 Skills 共享企业记录和工具，不各自引入能力插件。

企业插件以带版本的 SQLite 记录管理买家机会。每条记录保存买家身份、目标产品、匹配理由、采购信号、网页来源证据、阶段、联系人事实和下一步。`enterprise_opportunity_list` 在研究前读取已有记录，`enterprise_opportunity_save` 通过乐观并发创建和修订记录。进入已确认匹配及后续阶段时，必须至少包含一条 HTTP(S) 证据。

机会看板提供搜索、筛选、证据查看、阶段调整和可恢复归档。开始研究会在对话中加载随附 Skill，后续会话从同一条持久记录继续。对外联系、非公开联系人核实及采购关系声明不属于此闭环。

经过认证的 Connection 服务只接受精确路径。因此企业 Site 编辑器保留在 `/api/enterprise/sites`，把经过校验的 `siteId` 和 `action` 查询值映射为内部资源路由，不注册不受支持的占位符路径。
