# Agent Note: 供应商档案阅读与逐项维护

Status: implemented

[English](2026-09-20-supplier-profile-reading.md) | 中文

## Problem

阅读供应商档案需要理解产品供给及支持来源。一次展示所有可编辑声明和关系，会让阅读任务与数据维护相互干扰。

## Decision

[供应商工作区](../../../../trade/enterprise/src/client-supplier.tsx) 在大幅主视觉照片旁呈现企业定位。产品、案例与能力拥有独立图片区域、名称和简短说明；条件、买家标签与证据进入详情。概览中每个主要分类最多显示两个条目，次要业务内容折叠展示。搜索与分类筛选可查看其余条目。

可选的档案媒体字段保存主视觉素材及明确的图谱节点配图。选择器使用已上传图片，保留空图片区域，并支持上传、更换与移除。选择展示图片不创建证据、不核验图谱，也不授予外部访问。没有展示配图的对象可以使用其明确关联的图片证据。无关上传素材不会自动成为封面。移除展示关联保留文件；删除文件会清除档案中的对应图片关联。照片同时显示文件名称，包括独立演示中的生成示例标识。

供应商图谱保存可选的展示偏好，使主标题、简介、导向、栏目顺序与主推 ID 参与草稿版本和人工确认。自动展示根据结构化业务对象确定产品、服务或项目优先级，不依据企业名称关键词，也不生成营销声明。明确的选择可以保留空栏目并显示补充提示。次要内容仍可导航和搜索。主推引用必须存在；删除对象时清除其主推引用。媒体仍由企业档案独立保存。选择布局不核验声明，也不修改外部授权。共用渲染器调整主视觉比例、方案呈现及阅读顺序，不执行模型生成的页面代码。

对话仍是主要更新入口。手动维护每次选择一个对象或证据记录，并按需展开次要字段。所有编辑保留完整图谱作为独立草稿；取消未保存修改时需要选择是否放弃。保存与确认保持独立操作。可见的草稿提示和已确认版本切换区分当前显示内容与对外授权内容。

[企业数据归属决策](../architecture/2026-09-14-local-enterprise-workspace.zh.md) 继续负责持久化、整版确认、来源核对和外部披露。阅读布局不创建第二份档案，也不改变这些权威来源。

## Alternatives considered

**美化完整表单。** 颜色和间距无法从阅读任务中移除无关字段。表单属于明确的维护操作。

**逐卡片独立保存。** 声明可能引用图谱其他位置的证据和关系。保存完整草稿保留已有校验与版本检查。

## Consequences

浏览所需控件减少，同时保留精确维护入口。详情面板限制键盘焦点，在原入口仍挂载时恢复焦点，并在视口内滚动。浏览器测试通过正式 profile 验证搜索、单项选择、未保存修改取消、确认、来源读取和采购操作，并保存桌面及手机截图。这些测试不证明真实模型能够完成对话更新。
