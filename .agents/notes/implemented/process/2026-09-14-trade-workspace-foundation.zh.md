# Agent Note: 外贸 Workspace 开发底座

Status: implemented

[English](2026-09-14-trade-workspace-foundation.md) | 中文

## 问题

外贸工作区需要持续维护的 Agent 运行时和浏览器应用，并尽量降低上游维护成本。

## 决策

工作副本保留上游源码，使用从 `web` 派生的独立 `trade` profile（运行配置）。[开发辅助脚本](../../../../trade/dev.ps1) 调用构建后的上游 CLI（命令行界面），加载[部署补丁](../../../../trade/cordis.patch.yml)，将开发会话和凭证与用户常规 Harness 主目录分开。它在专用业务目录中启动，仅监听本机回环地址。[源码记录](../../../../trade/upstream.json) 标明基线及浅历史限制。

## 考虑过的替代方案

**立即使用 assistant-ui 替换前端。** 原生界面已提供验证底座所需的会话、文件和工作区控制能力。在产品需求得到验证前替换，会增加协议适配工作。

**立即增加第二套 agent loop（智能体循环）和记忆组件。** Harness 已负责会话、工具及执行。额外服务推迟到其业务归属和集成需求明确之后。

## 影响

此扩展不增加运行时框架依赖，也不改变上游 Agent 行为。部署属于本地单用户底座；独立目录不提供租户隔离。组织账户、业务持久化和检索属于后续实施工作。托管 Fork 需要目标仓库，本地辅助脚本不会创建它。
