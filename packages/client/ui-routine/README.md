# @deepseek-ai/dsh-client-ui-routine

English | [中文](README.zh.md)

The Routine Center adds a compact Session-header entry backed by the `routine` projection. It shows active plans, execution state, next run time, and the latest result without changing Schedule semantics. The panel is intentionally dense and action-oriented; full creation and run mutation wiring remains owned by the Host Routine Remote surface.
